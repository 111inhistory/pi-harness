## 边界

不新增迁移测试矩阵，不修改生产模块以识别 v1。复制与转换是一次性操作代码，只改新副本，不进入生产目录。旧历史只恢复所选当前位置状态；Rewind 到合成事件之前不会恢复当时的 v1 注册表。没有重写不透明的原生对话内容，没有把原任务重新执行作为批量验收。
