# 会话接口与 RPC 集成方案

## 当前实现

候选已接入 38 个公开方法与 128 个共享定义，协议版本为 2。Main 调用实际 SDK runtime，Root 切换保留宿主连接并替换领域绑定。SDK Main 宿主观察者跨重绑保留，旧 Root 观察者确定性释放；取消导航恢复原会话的领域服务。

根装配移至会话模块，Subagent 只安装工具与命令。Preset、审批与受管发送继续调用共享领域入口；RPC 不增加业务数据库、调度器或审批状态。扩展入口缺少完整 SDK runtime 时如实报告能力和 submitted 交接，不缓存 command context。

定向验证覆盖实际文件入口、SDK 输入准入和中断、新建／切换／fork／树导航／reload、取消恢复、订阅释放及端点发布失败。模型使用本地模拟实现。完整 Linux 门禁为 1041 通过、10 跳过，包含实际入口与 Preset 代次回归；独立暂存快照与最终工作树均通过。平台 CI 结果以对应提交运行记录为准，真实在线供应商未测。

## 保留的暂停检查点

`75ced6d3` 是先前按用户要求发布的未完成检查点，其类型错误和未完生命周期属于该历史提交。该提交与原工作树保留，不把过去的组件验证当作最终候选的验证结果。

## 接口边界

RPC 是现有业务操作的远程适配层。领域模块继续拥有权限、Preset、审批、会话和任务状态。TUI、模型工具与 RPC 调用相同的业务操作。

RPC 负责消息帧、参数校验、调用者绑定、结果传输与连接订阅。会话宿主组合领域服务并管理绑定和代次。RPC 不另建业务状态、任务调度或审批决定流程。

## 集成约束

近期 TUI 和 command 行为是业务基准。保留用户 enable 语义、隐藏工具检查、记录先于生效、稀疏 Preset、祖先与深度限制，以及结果未知时不自动重放。

Main 控制调用公开 SDK。新建、切换和 fork 由实际 `AgentSessionRuntime` 执行，宿主负责重新绑定。完整宿主持有连接，Root 切换时替换领域绑定并释放旧 Root 订阅，SDK Main 宿主观察者保留。

共享分支记录与 SDK 状态仍是权威数据。生成代码只消除机械重复，不决定业务归属或放宽权限。
