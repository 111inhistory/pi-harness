## 阅读规则

- 区分作者报告、静态分析、离线复现和真实端点验证。
- 引用实验结论时，应保留依赖版本、环境和适用条件。
- 未复现不表示问题不存在；局部通过也不表示完整用户链路通过。
- 审查记录中的修改方向应经确认后进入契约或架构文档。
- 后续实验推翻旧判断时，应注明被修正的范围，不静默扩大旧结论。
