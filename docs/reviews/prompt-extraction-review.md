# 提示词正文外置

## 结果

2026-10-25，Capability 与 Subagent 的提示词正文从执行代码移至 `prompts/`。工具描述、参数说明、检索规则、续跑说明、分支记忆指引和 Budget 收尾文字也使用独立文件。文件清单见 [`prompts/README.md`](../../prompts/README.md)。

- `src/prompt-text.mjs` 读取固定 UTF-8 文件，不做 trim 或静默回退。
- `src/subagent-prompt.mjs` 组装宿主数据，路由与执行共用任务装配。
- 角色说明与模型偏好继续来自用户路由配置。
- 权限、参数类型、来源绑定、预算裁决和执行生命周期仍由代码决定。
- UI 标签、协议枚举和运行错误不作为提示词正文外置。不引入模板框架或热更新机制。
- 分支记忆继续指向已声明的工具接口和 Skill 绝对入口，不恢复已删除的资源 URI 读取协议。

正文在模块初始化时读取。修改后应重启 Pi；不承诺 `/reload` 刷新全部 ESM 依赖。

## 验证

Linux、Node.js 22、锁定 Pi SDK 1.4.0 下：

- 外置前后的 Subagent 工具声明 JSON 字节快照一致，包含命名空间、描述、指引和参数 schema。
- 内部 Capability 的系统和用户提示词与原文一致。
- 回归覆盖任务上下文空白、消息来源、首次启动与续跑的区别、宿主值中的美元替换字符、Budget 文本和缺失文件错误。
- `npm run check` 通过：317 项测试，315 通过、0 失败、2 项既有环境跳过。类型检查通过，默认套件包含离线真实 SDK 管线。

测试证明本文描述的文字与调用契约，不证明模型一定遵守每条提示词。没有声称完成多轮模型质量或 Linux 长时间压力验收。
